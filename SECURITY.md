# Seguridad

## Reportar una vulnerabilidad

No publiques credenciales, tokens, claves API ni detalles explotables en issues públicos.

Para reportar una vulnerabilidad, utiliza la función de reporte privado de vulnerabilidades de GitHub en el repositorio OpenView. Incluye el componente afectado, el impacto observado, los pasos de reproducción y una posible mitigación.

## Reglas de seguridad del proyecto

- Las claves y credenciales se mantienen fuera del control de versiones.
- Los archivos de entorno locales deben permanecer ignorados por Git.
- Las fuentes externas se validan antes de incorporarse al dominio.
- Los proveedores declaran permisos de uso, atribución y redistribución.
- Las dependencias se revisan antes de incorporarse y se actualizan mediante cambios verificables.
- Los mensajes de error no exponen tokens, cabeceras de autorización ni datos privados.
