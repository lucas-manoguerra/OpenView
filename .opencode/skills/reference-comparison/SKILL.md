# Reference comparison skill

Use the public documentation and observable behavior of TradingView Lightweight Charts as a functional reference only.

Record the version inspected, configuration, inputs, event sequence and expected outputs. Separate facts from hypotheses.

Convert observations into acceptance criteria that can be tested in OpenView. Include normal use, boundaries, errors and interaction sequences.

Do not copy source code, internal tests, private identifiers, internal data structures or architecture. Do not depend on the reference library at runtime.

Recommend OpenView-owned contracts and algorithms based on product requirements. Record important differences as intentional design decisions.
